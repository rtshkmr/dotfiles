To enjoy the performance benefits of emacs 30, as well as to avoid some bugs and enjoy more modus themes, I've moved away from using the railwaycat port and am using the emacsplus port of emacs (for macos).

Refer to [[https://github.com/d12frosted/homebrew-emacs-plus?tab=readme-ov-file#install][this README for emacsplus port]].

** MacOS Specific
- see the emacsplus repo on how to setup the launchers
- also on how to setup emacsclient, helps make the loading of frames fast because there's a daemon at the back.
